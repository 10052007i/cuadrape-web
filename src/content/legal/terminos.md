## 1. Naturaleza del Sitio Web
El sitio web `cuadrape.com` cumple una función informativa y comercial para dar a conocer la solución tecnológica Cuadrape para hospedajes.

## 2. Condiciones de Contratación
- **Plan mensual**: El servicio de software tiene una tarifa mensual publicada en Soles (S/ 119 al mes, IGV incluido).
- **Implementación**: La configuración inicial y capacitación presencial tiene un costo de pago único (S/ 300, IGV incluido).
- **Sin Permanencia**: El servicio se presta mes a mes sin contratos de permanencia forzosa.

## 3. Propiedad Intelectual
Todos los elementos del sitio web (marcas, logotipos, código fuente, diseño y textos) son propiedad de Cuadrape. Queda prohibida su reproducción sin autorización previa.
