# Cuadrape Web (`cuadrape.com`)

Sitio estático comercial de marketing para **Cuadrape para Hospedajes**, desarrollado con Astro, Tailwind CSS y TypeScript.

## Requisitos
- Node.js versión fijada en `.nvmrc` (`v20.18.0`)
- npm

## Comandos

```bash
npm install            # Instalar dependencias
npm run dev            # Servidor de desarrollo en localhost:4321
npm run build          # Genera la salida estática en dist/
npm run preview        # Servidor de vista previa sobre dist/
npm run check          # Verificación de tipos de TypeScript y colecciones
npm run check:contenido # Auditoría de frases prohibidas sobre dist/
```
